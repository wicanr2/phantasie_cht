# 001 繪字事件與疊字核心

狀態：DRAFT（2026-10-03）。證據來源：`docs/re/003`、`005`、`006`、`007`。實作位置：dosgolem 分支 `phantasie-cht-overlay` 的 `apps/phantasie/`。

## 1. 範圍

| 項目 | 內容 |
|---|---|
| 納入 | 經 `0110:25A5`（IDA `sub_36A5`）繪出的玩家可見文字：覆繪成中文（基準語言 zh-TW，語言通道由 `004` 規定）。事件擷取、字串解析的介面、版面、疊字產生、失效以外的顯示規則 |

## 3. 事件擷取

兩個唯讀 hook，掛在最後一支載入的程式映像段 `img` 上（`PSP + 10h`；執行期為 `21AF`，隨載入位置而定，由 `ImageSeg` 取得）：

| hook | 位址 | 時機 | 讀取 |
|---|---|---|---|
| A | `img:26E9` | 格式化完成，取字模之前 | 欄 `[BP+4]`、列 `[BP+6]`、格式字串指標 `[BP+8]`、可變引數 `[BP+10 + 2i]`（讀 12 個字組）、返回位址 `[BP+2]`、`DS:3A36` 起的 NUL 結尾字串（最多 40 字元）、格式字串（最多 64 字元） |
| B | `img:277D` | 函式結尾，8 次視訊寫入已完成 | 無（只通知 A 的事件完成） |

`TextEvent` 欄位：步數、`Col`、`Row`、`Text`（已格式化）、`Format`、`FmtPtr`、`Args`（12 個原始字組）、`Caller`、`Overlay`。`Overlay` 由 overlay 載入器 hook（`img:3D0F`，`[SP+2]` 為檔名指標）維護：呼叫端位移 ≥ `53EA` 時記錄目前載入的 overlay 名稱，其餘為空字串。

規則：

1. A 與 B 成對。B 在對應的 A 之後、下一個 A 之前必到達（單一返回點；函式不會巢狀呼叫自己，因為格式化與繪製之間沒有呼叫端程式碼）。實作要檢查：B 到達時沒有對應的 A，計入 `unpaired` 並忽略。
2. hook 只讀記憶體，不修改機器狀態；同一輸入序列下，hook 開關不得改變任何步數時點的記憶體與視訊緩衝區雜湊（`005` 驗收）。
3. 文字長度大於 40 的部分不會被繪出；事件的有效文字是 `Text[:40]`。

## 4. 事件分類

對有效文字 `t = Text[:40]`：

| 類別 | 條件 | 處理 |
|---|---|---|
| E（空） | `len(t) = 0` | 不繪製，忽略 |
| N（非可列印） | 任一 byte 小於 `20h` 或大於 `7Eh` | 不翻譯；對事件矩形呼叫 `Layer.Clear`；計入 `nonprintable`，並以 byte 序列記錄種類 |
| T（文字） | 全部在 `20h` 至 `7Eh` | 交給 §5 解析 |

N 類包含視窗框線。框線不覆繪（`003` §7），所以也不產生疊字。N 類含可列印字元的混合行（例：框線字元夾字串）目前不覆繪；若量到，補規格。

事件矩形：`x0 = Col × 8`，`y0 = Row × 8`，`x1 = x0 + len(t) × 8`，`y1 = y0 + 8`。

## 5. 解析介面

```go
// Resolve 依 003 把一個 T 類事件解析成中文。ok=false 表示沒有譯文可用。
func (c *Catalog) Resolve(ev TextEvent) (zh []rune, key string, ok bool)
```

`Resolve` 是純函式：只讀 `TextEvent` 與 catalog，以及（為了 `%s` 引數）讀取原版記憶體中的字串。它不產生副作用。細節在 `003` §3 至 §5。

## 6. 版面

寬度單位為半格（`h`，4 個原版像素）：`20h` 至 `7Eh` 的 ASCII 字元佔 1 h，全形字元（`wide(r)`：`r ≥ U+2E80`，或 `U+FF00` 至 `U+FFEF`）佔 2 h。原文佔 `avail = 2 × len(t)` h。

1. `w(zh) ≤ avail`：照排；`w(zh) < avail` 時尾端以 ASCII 空白補滿 `avail`（遮住原文墨跡）。
2. `w(zh) > avail`：由左算起，保留不超過 `avail` h 的最長整字前綴；計入 `truncated`，記錄 key。lint（`003` §9）在發行前擋下會截斷的譯文，執行期截斷是最後一道防線。
3. 對齊：原文是置中（`003` §8）時，譯文在 `avail` 內置中（左右補白差 1 h 時，左側少）。其他情形靠左，保留譯文開頭的空白。
4. 譯文含 `\n` 或控制字元：視為格式錯誤，lint 擋下；執行期回 `ok=false`（不覆繪）。

## 7. 疊字

把排好的字串（含補白）切成連續的同寬度字元段（全形段 `CellW = 8`，半形段 `CellW = 4`），每段一筆 `xlate.Stamp`：

| 欄位 | 值 |
|---|---|
| `X` | `x0` 加上前面各段的寬度（原版像素） |
| `Y`、`CellH` | `y0`、`8` |
| `Cells`、`CellW`、`Text` | 該段的字元數、`8` 或 `4`、該段字元 |
| `Font`、`GlyphX`、`GlyphY`、`GlyphScale` | 語言通道字型（`004`），`0`、`0`、`1` |
| `Key` | catalog key（診斷用） |
| `State` | A 時設 `Printing`，B 時改為 `Pending` |
| `SwapColors`、`Transparent` | 不用 |

`Layer` 的 `W = 320`、`H = 200`，輸出倍率固定 2（全形字 16×16 恰好佔一個原版格）。

流程：

- T 類且 `ok=true`：A 時對事件的每一筆疊字呼叫 `Layer.Add`（舊疊字被整個蓋住時移除，部分重疊時被蓋的格轉透明）；B 時把這一批疊字設為 `Pending`。
- T 類且 `ok=false`：A 時對事件矩形呼叫 `Layer.Clear`，計入 `untranslated`，記錄 key（`Format` 與 `Text`）。原文照常顯示。
- `Layer.Frame` 可以在 A 與 B 之間執行：`Printing` 的疊字不被定色也不被顯示，所以半成品畫面不會被取樣；被 `Clear` 或 `Add` 波及的舊疊字只剩事件矩形之外的格，那些格不在繪製中。`Frame` 與 hook 在同一個 goroutine，只在 `RunUntil` 返回之間呼叫。

## 8. 定色與顯示

顏色由 `Layer.Frame` 在 `Pending` 疊字上取樣：矩形內出現最多的色號為背景，第二多為前景（`xlate.Colors`），再取該色號在畫面 RGB 中的值。前景背景同色（整塊單色）時前景等於背景，字會看不見；這是原版把該文字畫成同色的結果，不是覆繪缺陷（見 `AGENTS.md` §5）。

顯示：`Layer.Draw(dst, 2, missing)`，`dst` 是原版畫面放大 2 倍的 RGBA。疊字以外的像素逐點等於原版色號放大。

## 9. 診斷

計數器（只讀，可在收據輸出）：`events`、`translated`、`untranslated`（含 key 集合）、`nonprintable`、`truncated`、`missing_glyph`（`Draw` 的 `missing` 回呼）、`unpaired`。計數與記錄不得影響機器。

## 10. 驗收

1. 單元測試（純 Go，不需原版）：事件分類、半形全形切段、補白與截斷、置中、疊字欄位。期望值寫字面值。
2. 同狀態 A/B（需原版，缺檔則 SKIP 並說明不算驗收）：同一起始狀態、同一路線、同一固定步數：
   - 原版 `B800:0000` 起 `4000h` bytes 的雜湊，疊字開啟與關閉兩次相同；記憶體段（映像與 DGROUP）雜湊相同。
   - 疊字開啟時的 2 倍畫面，在疊字矩形之外與疊字關閉的 2 倍畫面逐點相同。
3. 覆蓋收據：每個接通路徑列出對應的 key、事件座標、疊字矩形與截圖；路徑至少含標題選單、城鎮上方選單列、公會選單、訊息視窗。
4. 負對照：關閉「`Clear` on untranslated」後，編寫一個先印中文、再以未譯英文覆寫同一位置的測試，應失敗（舊疊字殘留）。
