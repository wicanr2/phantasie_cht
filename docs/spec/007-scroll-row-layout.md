狀態：CONFORMED。日期：2026-10-04。範圍為卷軸 8 的正常閱讀抽樣及下列顯示契約，不代表 20 卷全部動態驗收。依賴已 CONFORMED 的 001、003、004；補足 005 的卷軸閱讀契約。使用者已授權中文化與 commit、push。契約對程式、資料對證據兩輪唯讀審查完成，巢狀語意與擴展區反白稽核的應改已清除；實作審查無阻擋或應改。

原版定位、輸入雜湊、工具版本與正常取得卷軸的證據：[015 卷軸閱讀](../re/015-scroll-reading.md)。只修改顯示，不改原版記憶體、資料、規則、存檔與玩家按鍵。

## 精確辨識與安全矩形

整行擴展僅接受以下條件全部成立的 EventRecord：overlay=`ov1`、Caller=`99F0`、FmtPtr=`C21D`、FmtKind=static、Format 恰為 `%s`、Col=0、Row=2..21、Composed=nil；恰有一個 ArgStr，Kind=buffer、Piece=nil、Ptr=Args[0]、Content=Text，Text 長 1..39 且全為可列印 ASCII，Cells 恰為 Text bytes。BP 非零，`BP+12+40*(Row-2)` 不超過 `FFFFh` 且等於引數指標。條件不符沿用原事件寬度。

批准的顯示矩形為 `[0,320) × [Row*8,Row*8+8)`，可用 80 半格。行高、列數與單行截斷規則不變。原文 Text、Cells、引數、位置與視訊寫入收據保持原始值；新增顯示寬度與遮罩輔助函式。擴展部分用虛擬空白遮罩，不能宣稱原版在尾端繪字。

提交、語言重建、影子還原、hidden 範圍、定色、反白分段與殘字稽核使用相同顯示範圍。尾端空白亦受指紋失效、還原閘門與稽核，不因擴展而跳過檢查。其他事件清除其實際寫入矩形；整頁清除與還原仍走 002。

位置 oracle 保留兩個獨立檢查：原版 Text 矩形必須等於真實 VideoWrite 足跡；疊字聯集必須恰好等於批准的顯示矩形。不得把原文補空白後冒充原版寫入足跡。正常卷軸路線在原生及 2 倍合成檢查差異範圍。

## 整行空白與置中

003 的 `<blank>` 只允許整句，增加一個明示例外：恆等模板恰為 `%s`、只有一個引數且沒有 Appends 時，該引數代表整句，非空白來源的 catalog 譯文恰為 `<blank>` 可解析為成功的空行。不能與引數或模板的置中標記並用。直接查表引數遇到帶字面前後綴、寬度／精度、其他轉換或追加文字時均拒絕為 badarg；包含 `<blank>` 與其他文字的譯文也拒絕。空譯文仍代表缺譯。巢狀 Piece 沿用 003 的已解析整句語意，不由本規格更改；上述拒絕條款僅限直接查表引數。

卷軸 8 標題鍵四語增加現有 `\c` 標記，不改譯名。其餘已置中的標題保持原值。本規格不批量改寫文字或 MESS 版面。字型從正式 catalog 重建並核對覆蓋。

## 實作與驗收

引擎修改位於 `apps/phantasie/` 的版面輔助、overlay、recolor、audit、shadow、position、resolve 與必要測試。001 原事件矩形契約僅由本規格對精確卷軸事件補充。003 整句空白契約增加上述例外。通用 CPU、DOS、BIOS 與原版執行層不改。

1. 合成測試用虛構 ASCII 文本，逐一否定辨識欄位、邊界列、溢位與不一致 Cells。短來源、長譯文須完整顯示；置中位置與右緣 320 有字面期望值，短原文足跡另以字面值檢查；原始事件未被改寫。
2. 空白標記測試涵蓋 `%s` 成功，`%s `、` %s`、前後綴、多引數、寬度、精度、Appends、置中及混合文字拒絕。巢狀整句空白保留既有語意；原有非卷軸版面與解析回歸保持通過。
3. 正常取得、閱讀、輸入 n 不列印、返回原畫面，四語及英文切換驗證。標題置中、正文完整、空白行不出標記、不殘字。已有存讀檔收據回歸；本規格不變更存檔格式。
4. 四語 hooks none、overlay off、overlay on 與另一 Frame 節奏，steps、reads、VRAM、完整 1 MiB 記憶體相同，兩種節奏的 Layer 相同。PASS 之外另查截斷鍵與實際畫面，不能把「有命中鍵」當正文完整證據。
5. 尾端被其他文字重畫、部分清除、語言切換與影子還原的合成測試須驗證擴展區失效。只反白擴展區時，定色與遮罩稽核都必須使用擴展格的逐格狀態，不以原文長度之外一律未反白。故障注入關掉整行寬度或空白處理，對應驗收必須失敗。
6. 原版資料、手冊與含答案的路線仍只留本機；可版控的卷軸路線不含答案或原版全文。兩輪唯讀審查後升 READY，通過同狀態與負對照才升 CONFORMED。
