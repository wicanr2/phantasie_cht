# 006 手冊答案提示

狀態：CONFORMED。日期：2026-10-04。範圍為下列正常路線抽樣，不代表 154 題全部動態驗收。

## 授權與證據

使用者要求接手 Claude 的手冊提示工作，上網下載 Phantasie 手冊並直接顯示答案。取代 `003` §9 對已核對題目一律不覆繪的處理；其他保護清單行為不變。

來源、輸入雜湊、IDA 版本與原始定位見 [012 手冊來源與提示事件](../re/012-manual-prompts.md)。只改輸出層，不修改原版資料、記憶體、選項或判定，不自動送鍵。英文通道照既有契約關閉覆繪。

## 本機資料

- 新增可選翻譯家族 `text/manual.<lang>.tsv`，三欄 `key`、`translation`、`source`，沿用 `ParseCatalogTSV`。四個翻譯語言各自載入。這些檔案含答案，加入 `.gitignore`，不提交或散布。
- 鍵為 `prompt:item`、`prompt:spell`、`item:<原版物品縮寫>`、`spell:<十進位編號>`。前兩筆是題型標題，後兩類為已經排好的提示文字。譯文不得再解讀成 printf 模板。
- 題型標題與答案句型由可版控的 `text/manual-labels.<lang>.tsv` 提供，三個鍵為 `prompt:item`、`prompt:spell`、`answer`。只有 `answer` 允許恰好一個 `%s`，builder 用手冊核對值替換後輸出純文字；這份標籤檔不含答案。
- 答案來自手冊。法術的數字等級轉為畫面既有羅馬數字名稱，並沿用現有各語言的法術譯名，讓提示能與選項對照。原版縮寫對照只作定位。核對表、腳本輸入與作答路線放 `workplace/manual-derived/`。
- 可提交的工具 `tools/build_manual_catalog.py` 只接受外部三欄資料表，不內嵌答案，輸出四個語言的本機 catalog。來源欄保留手冊 SHA-256 與頁碼。工具專門檢查物品編號 1 至 100 的唯一性、法術編號 1 至 54 的完整性、非空來源、控制碼及最小事件寬度；本家族不套用通用 UI lint 的 printf 與鍵長量寬規則。字型重建與執行期共同檢查字模覆蓋。
- 缺少檔案時維持原版提示。解析錯誤只停用該語言的手冊提示，保留一般中文化，並回報診斷。缺鍵、空值、缺字或文字超出安全矩形時退回原文，不顯示截斷的答案。
- `tools/build_fonts.sh` 在本機手冊 catalog 存在時一併烘製字型。字型產物仍只留本機。

工具入口：在 Docker 內執行 `python -B tools/build_manual_catalog.py --reference workplace/manual-derived/answers.tsv --text text`，再以 `tools/build_fonts.sh` 重建字型。合成反例入口為 `python -B tools/tests/manual_cases.py`；執行期測試位於 dosgolem `apps/phantasie/manual_test.go`。

## 事件辨識

`Resolver` 在保護清單檢查之前嘗試本機手冊提示。四個事件必須同時符合：`KindStatic`、無組句、overlay 名稱恰為實測值 `ov2`、`Caller`、`FmtPtr`、座標、格式字串與引數生成的原文一致。只接受下表，不用廣泛的字串包含判斷。

| 事件 | Caller | FmtPtr | 欄、列 | 格式 | 查表鍵 |
|---|---|---|---|---|---|
| 物品首行 | B795 | C1BC | 0、10 | `What is the item number of a%c` | `prompt:item` |
| 物品次行 | B7B4 | C1DB | 0、11 | `%s? (page 15,16)` | `item:` 加唯一靜態 `%s` 引數 |
| 法術首行 | B848 | C1F3 | 0、10 | `What is the name` | `prompt:spell` |
| 法術次行 | B861 | C204 | 0、11 | `of spell %d? (back cover)` | `spell:` 加範圍 1 至 54 的引數 |

物品首行 `%c` 僅接受空白或 `n`。物品次行引數必須是可列印 ASCII、種類為 `KindStatic`。缺少本機答案或辨識不合時，仍走 `WhyProtected`，收據保持失敗，不以放寬保護清單掩蓋漏接。

## 排版與失效

- 安全矩形沿用原事件：`x=Col*8`、`y=Row*8`、寬 `len(Text)*8`、高 8 個原版像素。2 倍合成以 16 高字型畫一列。只清原事件墨跡，不額外覆蓋選項。
- 依當前語言的實際字型寬度量測，提示超寬、控制字元、置中標記或缺字就退回原文。答案不可截斷或用省略號。
- 成功時以一般 `Result` 進入既有疊字核心，`Hits` 記本機 catalog 鍵，沿用反白、頁面影子、清除、語言切換與稽核。
- 語言切換驗收使用四份完整 catalog 與英文。切到缺少本機提示的語言會依既有解析器移除該疊字；切回後須等待原版重畫才恢復，這是既有缺譯重建限制。本規格不擴充通用失效核心。
- 手冊提示的字元只來自本機 TSV。合成畫面與存檔分離，A/B 的原版記憶體與 VRAM 雜湊仍須相同。

## 驗收與影響

修改 dosgolem `apps/phantasie/` 的 catalog、語言載入、解析器與相關測試。`Resolver` 增加 Font 參照，手冊提示必須在 commit、rebuild、shadow restore 三個入口檢查字模與寬度；缺 Font 時不顯示提示。前端與收據工具回報手冊 catalog 載入錯誤。原版執行器、CPU、鍵盤與存檔不改。

1. 合成測試用虛構名稱與值，不使用真實答案。涵蓋四個呼叫位置、錯誤 overlay／座標／Caller／FmtPtr／引數／原文，缺檔、錯欄、重複鍵、空值、缺字、過長、語言切換與清除。
2. 本機表核對 100 個物品與 54 個法術；靜態來源一致性不等於 154 題全部動態驗收。
3. 從正常玩家路線到題目，核對提示與手冊，按畫面的正確選項後回到遊戲，確認清除。作答路線與畫面只留本機。
4. 同一路線以 hooks none、overlay off、overlay on 及另一 Frame 節奏重跑。每個檢查點 steps、reads、VRAM、全記憶體必須相同；兩種 Frame 節奏的疊字相同。原生與 2 倍合成的變動限於既有批准格。既有 `mem_hash` 只涵蓋映像至 DGROUP 末端；本次在 TSV 尾端加 `full_mem_hash`，SHA-256 範圍為 dosgolem 實模式實體 `00000h` 至 `FFFFFh` 的 1 MiB，不移動既有欄位。
5. 關掉本機答案查表作負對照，題目恢復原文且對應提示驗收失敗。
6. 已有城鎮與戰鬥路線回歸；本機與發行用字型來源一致，無本機答案檔時一般語言通道仍可用。

只有被正常路線同狀態收據覆蓋的分支稱為已接通。靜態推論、合成測試與未量到分支分開列出。
