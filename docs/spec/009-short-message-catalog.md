# 009 短訊息正文 catalog

狀態：CONFORMED。日期：2026-10-04。依據：[RE018](../re/018-short-message-reachability.md)。前置：001、003、004、008 CONFORMED；引擎基準 `60b76b3`。

## 範圍

補齊已正常到達的 MESS5 索引 61 正文。引擎攔截、解析、畫面操作、選項與原版判定沿用現行實作。本切片不宣稱其他短訊息、其他欄寬、地牢存檔或整份 005 完成。

## 契約

1. `tools/prose_export.py` 新增可重複的 `--include-short <單位 id>`。沒有旗標時保留略過所有短訊息的現行行為；本次正式使用 `mess5:61`。指定的 id 必須存在、種類為 short、正文非空且無控制標記，否則以非零離開。所有指定項目都須在建立或寫入任何輸出前完成預檢；失敗時既有輸出不變。未指定的短訊息仍略過。重複 id 去重，依原始單位順序輸出；保留既有第三個位置參數指定批次大小的介面。
2. 輸出的正文及選項沿用 `gamedata.py` 已切出的欄位。不能把整個 40-byte chunk 當正文；MESS5:61 正文只有 10 bytes，保留其 `len/lead/trail`、開頭空白與來源 id。現有 MESS TSV 已去除選項尾端空白，匯出沿用規範化欄位，不由 TSV 猜補欄寬。原版兩個 11-byte 選項的實際寬度由動態記錄及唯讀原版另核對。
3. 使用既有 `prose_build.py` 產生正文鍵 `h:0e0313c80f15`。譯文用正式四語 TSV 保存，來源 `mess5:61#0`。翻譯為 zh-TW「寶箱。」、zh-CN「宝箱。」、ja「宝箱。」、ko「상자.」，沿用既有置中規則。兩個共用選項鍵及所有其他既有 catalog 列保持原值。
4. 正文安全範圍為列 5、欄 0 的 10 個原版 8×8 字格，即 80×8 像素。選項安全範圍為列 7、8、欄 14，各 88×8 像素。換行、字寬與顏色沿用 001、004，不能擴大清除範圍來容納譯文。
5. 新增譯文後，本機及可發行字型都由正式 TSV 重建。核對全部要求字元可用；若結果雜湊不變，保存重建收據。沒有字型來源或缺字時不能宣稱已驗收。
6. 原版程式、資料、記憶體、VRAM、亂數、選項與判定保持原樣。原版手冊、答案、正文匯出及含原版素材的收據維持本機。

## 驗收

- 匯出工具以合成輸入驗證預設略過、明示納入、重複 id、未知 id、非 short id、空正文與控制標記。混合有效與無效 id，以既有輸出檔作哨兵，確認非零離開且輸出全部不變。再以唯讀原版核對 `mess5:61` 的 L、正文、選項及雜湊；原版缺席時明示 SKIP。
- 正常路線沿用 RE018，涵蓋反白、兩個選擇、清除、移動及重訪。五個選項停點必須明示三個必備鍵並確認三個文字記錄均存在，不能只看既有 verdict。返回、移動及開啟結果要求三鍵消失；開啟結果另外核對原版物品保留提示。
- 四語的 none/off/on/on-f2 核對步數、讀鍵數、完整原版記憶體、映像及 VRAM 相同；on 與另一 Frame 節奏的 Layer 相同。無文字旅行點只作原版狀態診斷，不能算 UI PASS。其餘旅行分支若有 FAIL，逐項說明並保留整份 005 READY。
- 獨立核對五個選項停點的全文、置中、反白、字模及原生與兩倍像素範圍。正文必須在原版 10 字格內完整顯示；返回及移動後三個訊息鍵不可殘留。
- 以只刪除新正文列的本機 catalog 副本做負對照。必備鍵或獨立全文核對必須失敗；不能因既有 verifier 的 PASS 或其他選項仍有疊字而判通過。
- 用既有拉桿路線及一般譯文 lint 做最小充分回歸。沒有改 engine、ui catalog 或既有譯文時，不宣稱重跑全部玩家功能。

### 實作期間的處置與限制

- 私有正常路線保留 85 個無文字旅行停點。on/on-f2 的工具把它們標為「疊字數為 0」並回傳非零；逐點確認只有這一種非目標診斷。它們只用來比較原版狀態，不宣稱整條路線 UI PASS。正式中文化結論只涵蓋八個短訊息停點。
- none 模式的 `image_hash` 是 `-`，工具不產生覆繪圖片。檢查只比較其實際提供的原版狀態欄位，不將缺值當作圖片雜湊；原版狀態核對仍完整保留。
- 初次 lint 缺少來源字型與保護清單參數，初次收據批次把旅行點的退出碼視為產品失敗。補正命令及範圍後在同一工具鏈乾淨重跑；分類為驗證腳本問題。
- 其他短訊息、九個 3 字元選項及 005 的其餘分支仍未量到。此處不外推它們已中文化。
