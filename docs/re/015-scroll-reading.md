## 原始定位與範圍

以下為已證實的 IDA 靜態控制流。IDA 線性位址以 `1100h` 為載入基址；執行期偏移另列，不混用。

| IDA 線性定位 | bytes／運算元 | 語意 |
|---|---|---|
| `AA96` | `81 C4 DA FC` 於 `AA99` | 函式在堆疊配置卷軸緩衝區 |
| `AAA5` | `E8 F4 80` | 呼叫 `sub_2B9C` 讀取並解碼 800 bytes |
| `AAAB` 至 `AAB9` | `27h`、`18h`、四個零；`E8 EB 9E` | 呼叫既有 `sub_49A7` 清除整頁，欄 0 至 39、列 0 至 24 |
| `AAC7` | `3D 14 00` | 20 行迴圈 |
| `AACE` 至 `AADC` | `shl`、`add`、`lea cx,[bp+var_326]` | 引數為緩衝區加 `40*i` |
| `AADF` | `B8 1D C2` | 格式字串近指標 `DS:C21D`，內容 `%s` |
| `AAE6`、`AAEA` | `05 02 00`、`33 C0` | 列 `i+2`、欄 0 |
| `AAED` | `E8 B5 8B` | 呼叫 `sub_36A5`；執行期返回偏移 `99F0` |
| `AB03` | `E8 9F 8B` | 列 24 的列印詢問，與正文事件分開 |

正文每行可用整頁寬 320 像素、高 8 像素，列 2 至 21。原版 NUL 終止行最多 39 字元，短行右側仍為清頁留下的空白。這個範圍不適用其他 `%s` 消費端或列 24。

`sub_2B9C` 的 800 bytes 讀取及解碼證據見 [007 §3](007-message-and-scroll-formats.md#3-scrollsdtx)。本次另核對 `sub_49A7` 的參數流：`49AD: 0D 00 06` 設 AH=06h，清除行數 AL=0、BH=0，CX=0000h、DX=1827h。靜態資料核對 20 卷共 400 行，均為可列印 ASCII 且有 NUL 終止，最長 37 字元；不因此稱為 20 卷動態驗收。

## 正常玩家路線

`scroll-read-emitted.route` 從原版啟動、建立 Alice，走銀行提領 256 GP，武器店買卷軸 8，剩 135 GP。城鎮選項的「使用物品」選 Alice，再選已買到的卷軸。不改存檔、不授予物品、不寫原版記憶體。

動態探針 `scroll_probe.go` 匯出 `scroll-events.jsonl`。13 筆非空正文事件的 Caller 為 `99F0`、overlay 為 `ov1`、格式為 `%s`、FmtPtr 為 `C21D`、FmtKind 為 static，唯一引數為 buffer。事件文字等於引數及原版 Cells。引數近指標為 `BP+12+40*(Row-2)`，沒有 16 位元溢位。13 行的原版文字右側至 x=320 均為黑色空白。等級：已證實的正常路線抽樣，不宣稱其他 19 卷皆逐頁動態驗收。

既有譯文把整段重排至各行；zh-TW、zh-CN 有四個 `<blank>`，ko 有一個。解析器把 `%s` 的整行空白標記當成可列印文字。另有一條譯文受短原文行寬截斷，四語標題缺少置中標記。這些為已證實的顯示缺陷。

修復契約與驗收入口：[007 卷軸整行顯示](../spec/007-scroll-row-layout.md)。
