## 正常玩家路線的限制

從已驗收寶箱路線的正常返回 `(12,10)` 接續，按原版方向鍵前往 DNG5 `(22,13)` 的 MESS5:72 格。原始 DNG5 格值為 230、事件記錄檔偏移 1320、bytes `48 01 37 00 00`，來源鏈沿用 [014](014-dungeon-message-trigger.md)。只讀座標與繪字追蹤確認走到 `(8,7)` 後發生戰鬥，隊伍在原版戰鬥中全滅並返回大地圖。未到達訊息格，不作新 UI 驗收。

私人按鍵及原始輸出為 `gap-live.route`、`gap-live-trace.jsonl`；探針 `gap_live.go` 只記錄原版資料，不寫記憶體。實際全滅的最後停點為 784,736,717 步、453 次讀鍵、OUT1 `(20,5)`。本次工作容器已停止；不是因觀察逾時重啟或選取有利亂數結果。

候選資料與正常畫面狀態分開記錄。兩輪唯讀審查無阻擋或應改，012 的資料實作已完成，抽樣收斂見文末。沒有正常 UI 收據的單位仍為未量到，整體中文化未完成。

## 資料納入與回歸結果

兩輪規格審查及實作複核無阻擋或應改，四語各新增 16 列，prose 現為 1044、ui 678，合計 1722。舊 1028 列完整保留；固定原版 bytes 獨立推導的 16 個鍵全部覆蓋，六個字母選項完整保留既有規範化原文。資料預檢的缺一列及錯一字母副本每語兩個，八個負對照均拒絕。四語 lint 零錯誤，既有 UI 警告 20、20、27、27。

四語正式本機字型從相同 Unifont 17.0.05 重建，繁中、簡中、日文各新增兩個字模，韓文不變。舊字模 bytes 逐筆相同。字型來源與授權入口為 [font](../../font/README.md)，沒有新增發行包或更改待定條款。

正常寶箱回歸四語 on 與 zh-TW off 共 780 個原版狀態及 PNG 與既有收據相同，32 個既有寶箱 UI PASS，英文原版 156 點相同。此證據只支持既有畫面不受影響。其後 [027](027-dungeon-six-recovered-message.md) 已驗收 MESS6:52 的正常四語正文及返回清除；其他 15 個新增鍵未逐鍵量到，現行狀態依 012 的抽樣契約收斂。

修正後 403 個本機匯出單位與三個水池正文的 985 個相異源鍵，四語皆有非空正式譯文；核對清冊為 `gap-static-coverage.json`。其範圍是已列舉靜態資料，不涵蓋其他未列舉輸出或新增正常 UI。

私有工具與清冊為 `gap_catalog.py`、`gap-catalog-precheck.json`、`gap-catalog-verification.json`、`gap-chest-regression-summary.json`、`gap-verification-manifest.json`；範圍與工具版本見 [012](../spec/012-recovered-prose-catalog.md)。原版、引擎、二進位、手冊及答案表、正式 IDA 與 23 條公開路線不變。回填入口為 003、004、009、011、025、索引、CONTEXT 及分期目標。
