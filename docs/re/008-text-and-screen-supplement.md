# 008 文字與畫面路徑的補充證據

日期：2026-10-03。來源：`docs/re/003`、`005`、`007` 之後的靜態讀碼（`workplace/ida/out/*.asm`）、`textlog -args -ops -sprintf -int10 -pages` 動態記錄、隨機按鍵路線收集（約 4000 鍵 × 多條）與兩份獨立審查。IDA 位址 = 載入映像位移 + `1100h`；`ds:word_XXXXX` 的 DGROUP 偏移 = `XXXXX - 0DAF0h`。證據等級：已證實、強推論、假說、未知。本檔不含原版文字，只記位址、函式與統計。

正常死亡組句的四語全文、玩家指標與同狀態驗收已補於 [020](020-combat-death-messages.md)，原始定位為 dosgolem 映像返回 `A1E2`、`DGROUP:638E`。本檔早期組句機制證據保持有效。

## 2. 卷軸與訊息的繪出形式

## 5. 停用項目變暗（`0740`）

`0740`（IDA `sub_1840(row, col, width)`）對一列 20 格的第 2、4 條偶數掃描線（`B800` bank，偏移 `+50h`、`+A0h`）逐 byte 寫 `0`（`sub_5EC5` 逐 byte 寫入）。呼叫者是 `sub_26F6(欄, 列, 索引, 上限)`：先畫項目文字，再依 `上限 < 索引 mod 4 + 1` 呼叫 `0740`，是清單中不可選項目的變暗效果。呼叫點共 10 處（常駐 2、OV1 4、OV2 4）。清單捲動 `sub_249C` 依序呼叫反白、`AH=06h AL=1` 捲動、反白、繪新列。等級：已證實（讀碼）；動態未走到。

## 7. 原版格式化核心 `sub_5032` 的語意

數字與字串共用長度判定：精度 `P` 為「最多輸出的字元數」，不補零（`%-4.3d` 對 5 輸出 `5` 加 3 個空白，對 1234 輸出 `123` 加 1 個空白）；補零只由旗標 `0` 控制，且只作用於寬度的左補白。轉換跳轉表支援 `c d e f g o s u x`，其他字母原樣輸出；寬度與精度可用 `*`，原版格式字串未使用。格式字串使用的規格：`%s %d %u %c %ld %lu`，旗標只有 `-`，另有無旗標的寬度與 `%-d`；`%%` 靜態未見。等級：已證實（讀碼：`phantasi.asm` `10096-10099`、`10312-10418`）。

## 8. 手冊對照提示

OV2 入口所在的函式（IDA `sub_C7C4`，由 `sub_A801` 呼叫）在一個尚未檢查的旗標（`DS:C5F8` 旁的 `word_1A0EC`）為 0 時，以隨機數條件決定是否出題；題目字串包含「物品編號」「第 15、16 頁」「封底」等外部資料的指涉，共 4 個格式或字面字串。存在與位置為已證實；本次靜態盤點只確認隨機數判斷。後續已依使用者授權取得手冊，接通物品與法術提示，正常路線證據與素材邊界見 [012](012-manual-prompts.md) 及 [規格 006](../spec/006-manual-answer-hints.md)。早期沒有手冊及停止作答的紀錄留在 `WORKLOG.md`。

## 9. 其他直接寫視訊記憶體的函式

除 `25A5` 與整頁操作外，直接寫 `B800`、`BA00` 的函式都是圖形或遊戲狀態用途，沒有字模表：

- 常駐：`sub_301C`（`1F1C`，第 0 列存到堆疊再還原，內含 `25A5(0, 0, ...)` 的一次訊息列）、`sub_41AC`（`30AC`，圖形區塊）、`sub_4C45`（`3B45`，逐像素點）。
- OV1：`sub_6B84`（由 overlay 資料區往螢幕複製區塊）。
- OV2：`sub_AE40`（圖樣段 `INT 62h`、`63h`，含遮罩模式）、`sub_B20C`（矩形逐 byte 寫 0）、`sub_B6EC`（9×8 圖樣 XOR）、`sub_B8A1`、`sub_B9D6`（地圖格）。`sub_BE05` 不寫視訊，是把螢幕寫進存檔。

位元組掃描（`FONT` 位址 `3244h`、`3245h` 與 `3A36h` 在常駐與兩個 overlay 全範圍）：只有 `sub_36A5`（讀）、`sub_389D`（載入字模檔）、`sub_5FE5`（啟動清零）與 `sub_3885`（字元寫入回呼）。沒有第二條取字模路徑。`docs/re/004` 的「overlay 不寫視訊記憶體」不成立。等級：已證實。
