## 正常入口

等級：已證實，限固定 DOS 時鐘與這條正常輸入路線。

- 正常建立四人隊伍、離城，從 OUT1 經 OUT5、OUT9 到 OUT13。途中遭遇依原版選單逃跑或乞求饒命，保留原版金錢扣除與傷亡。
- OUT13 `(3,14)` 的原版入口確認後，進入第四地牢 `(15,0)`。停點 `original-path-116` 為 191611646 步、288 次讀鍵、狀態 3。
- 入口特殊記錄位於 `OUT13.DAT` 檔案偏移 `0x0212`，bytes 為 `03 0E 04 0F 00`。IDA 線性 `sub_8267` 的 `0x82A8` 呼叫 `sub_C6F0`，`0x82BD`、`0x82CC`、`0x82DE` 分別寫入地牢及入口座標，後續載入資料；動態位置與記錄吻合。
- 位置探針只讀 `DGROUP:751A`、`751C`，區域、地牢、訊息及狀態只讀 `64EA`、`64EC`、`64F6`、`64FC`。未修改位置、物品、記憶體、VRAM、存檔或原版判定。
- 正常路線沿東側到 `(22,21)`，再向西到 `(14,21)` 遭遇戰鬥。最後停點為 500156324 步、483 次讀鍵、狀態 4。三名隊員死亡，路線停在戰鬥選單，沒有到達目標九選項格。

私有正常輸入、探針、原始文字及影像保存在 `workplace/explore-dungeon/`。路線入口為 `dng4-battle-screen-prefix.route`、`dng4-live.route`；追蹤檔為 `dng4-live-trace.jsonl`，探針為 `travel_live.go`。這些檔案含手冊作答資料，不加入版控。

## 其他觀察與限制

- 正常路線在 `(22,17)` 遇到物品手冊題。既有正式覆繪工具顯示本機手冊提示，正常數字鍵作答後返回地牢。手冊、答案及選項不寫入本檔。
- 本機 `dng4-manual-pilot-v2` 共 189 個停點。目標提示有兩個預期鍵，外露及殘字計數為零；verdict 仍為 FAIL，原因是路線沒有宣告已知分隔線鍵。未把這份探索收據計入正式 UI PASS，也未宣稱本輪重跑四語手冊驗收。
- 目標收據有 `op_load2=9`，證明這條正常路線觸發過鉤子。沒有逐操作的同狀態及失效核對，規格 002 的 `load2` 分支仍未驗收。
- 早期候選 OUT10 的特殊格實際進入城鎮。特殊記錄的數值要與地形及消費端一起解讀，不能僅憑第三個 byte 認定為地牢。
- 完整本機證據清冊為 `workplace/explore-dungeon/dng4-research-manifest.json`。探索沒有改引擎、catalog、字型或公開路線。九選項及其他短訊息仍待驗收；兩個死亡畫面的後續驗收見 020。
