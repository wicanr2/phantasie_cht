# 003 IDA 靜態盤點（常駐映像）

日期：2026-10-03。範圍：`PHANTASI.EXE` 經 LZEXE 解壓後的常駐映像（不含 `OV1.OVR`、`OV2.OVR`）。
輸入是 `002-probe-receipt.md` 取得的傾印，SHA-256 `044b077aaba8b8dba484f2799d5a4086fbbac87e36bb9e76078977c69c6d0c38`，117,232 bytes。
證據等級：已證實、強推論、假說、未知。

## 位址慣例

| 寫法 | 意義 |
|---|---|
| `0110:xxxx` | 執行期 CS:IP。映像偏移等於 `xxxx` |
| IDA 名稱 `sub_NNNN` | `NNNN` 是 IDA 線性位址，等於映像偏移加 `0x1100` |
| `DGROUP:xxxx` | DS=`0DAF` 的資料段偏移，IDA 線性位址等於 `0xDAF0 + xxxx` |

本文以 `0110:xxxx` 為主，括號內附 IDA 名稱。

## 方法與工具

| 項目 | 值 |
|---|---|
| IDA 映像 | `ida-pro-9.4-idapython:locked-v1`，image ID `sha256:6f6d59af49d0008c4109a5295b5f374bdc007e2d1ab28cb9de08779584de2780` |
| 載入 | `idat -A -c -p8086 -Tbinary -b110`，載入段 `0110` |
| 腳本 | `tools/ida/ida.sh survey` 呼叫 `tools/ida/export_survey.py`；輸出 `workplace/ida/out/survey.json` 與 `phantasi.asm`（不進版控） |
| 容器 | `--rm --network none --memory 3g --cpus 2 --pids-limit 256`，目前 UID/GID；每次重建一次性資料庫 |
| 段位元數 | 載入器給 32 位元，腳本改為 16 位元 |
| 預設 DS、SS | 設為 `0DAF`。不設時 IDA 假設 DS 等於程式碼段，把 `mov bx,[0002]`（DS=PSP 時讀 PSP:0002）當成映像內資料，擋住 `main` 的解碼 |
| 種子 | 進入點 `0110:4EE5`；另以 MSC 框架序言 `55 8B EC`、`55 89 E5` 為啟發式種子（僅程式碼區） |
| 獨立交叉檢查 | 另以位元組掃描（Docker 內 Python）核對呼叫點，不依賴 IDA 可達範圍 |

### 覆蓋

| 項目 | 值 |
|---|---|
| 進入點可達函式 | 59 個 |
| 加框架序言種子後 | 206 個（嘗試 148 處，成功 146 處） |
| 已解碼程式碼 | 8,042 bytes，佔程式碼區（51,696 bytes）的 15.6%；全映像含資料段為 117,232 bytes |

覆蓋率低。程式碼區（`0110:0000` 至 `0110:C9EF`）的大部分沒有被分析到：沒有框架序言的函式、從函式指標或 overlay 呼叫的函式，都不在已建立的 206 個函式內。下列結論只涵蓋已分析的區域與位元組掃描的結果；「沒有找到」不等於「不存在」。

## 發現

| # | 發現 | 位置 | 等級 |
|---|---|---|---|
| 1 | 程式開頭是 C 風格啟動碼：`mov bp,0DAFh`、縮減記憶體區塊（`AH=4Ah`）、從 `DGROUP:3244` 清零至 `B8F0h`、掃描環境區塊、解析命令列、`call 0110:0000`（`main(argc, argv)`）、`AH=4Ch` 結束。形態與 Microsoft C 的啟動碼相近，編譯器與版本未驗證 | `0110:4EE5`（`sub_5FE5`） | 反組譯內容已證實；編譯器為假說 |

### `INT 10h` 包裝函式

`AH` 與暫存器取自函式本體；BIOS 服務名稱為標準 `INT 10h` 定義。

| `0110:` | IDA 名稱 | AH | 暫存器與內容 |
|---|---|---|---|
| `3A9B` | `sub_4B9B` | `00h` | `AL = 參數 & 0Fh`，設定視訊模式 |
| `376E` | `sub_486E` | `02h` | `BH=0`、`DH=參數2`、`DL=參數0`，設定游標位置 |
| `38A7` | `sub_49A7` | `06h` | `AL=參數0`、`BH=參數2`，`CX`、`DX` 由其餘參數組成，視窗上捲 |
| `38ED` | `sub_49ED` | `07h` | 同上，視窗下捲 |
| `3ABD` | `sub_4BBD` | `0Bh` | `BH=1`、`BL = 參數 & 1`，CGA 調色盤選擇 |
| `3AE8` | `sub_4BE8` | `06h` 與 `0Bh` | 先以 `AL=0`、`CX=0`、`DX=184Fh`（0,0 至 24,79）清整個畫面，`BH` 為前景與背景組成的屬性；再 `AH=0Bh`、`BX=參數4` 設背景與邊框色 |
